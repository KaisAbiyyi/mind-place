# Let Claude Code or Antigravity read your Mind Place memory

> Generated by `node scripts/mcp-local-read-setup.mjs guides` from `scripts/lib/mcp-local-read-setup.mjs`. Do not edit by hand. Indonesian: [mcp-local-read.id.md](mcp-local-read.id.md).

## What this sets up

- One of these coding tools on this computer can **search and read** the chats you allow. It can never change anything.
- It gets exactly three read tools, named one by one: `memory_search`, `memory_fetch`, `context_build`. No wildcard, no automatic approval, nothing else.
- Which chats it can read is decided only in Mind Place, under **Choose chats**. You can turn it off at any time.
- This guide covers Claude Code and Antigravity only. The Claude app, Gemini CLI and hosted apps are set up differently.

## Before you start

1. Open Mind Place and unlock it. Leave it open while you use the tool.
2. Go to **Connections** and turn on **Share memory with AI apps**.
3. Under **Name of the app** type the tool name (for example `Claude Code`), then press **Create access**.
4. **Copy your key now**: it is shown only once. Do not paste it into a chat, a file, a command or a screenshot.
5. Press **Choose chats** for that app and allow only the chats it should read.

## Give the key to this window only

Open PowerShell 7 in the project folder you will work in. Paste the key when asked; it is not shown and is not saved in your command history. The key lasts only as long as this window.

```powershell
$env:MIND_PLACE_MCP_TOKEN = Read-Host -MaskInput 'Mind Place key'
```

Start the tool from **this same window**. If you close it, repeat this step.

## Claude Code

From a Mind Place checkout, write the two files into your project folder (existing files are never overwritten):

```powershell
node scripts/mcp-local-read-setup.mjs write claude-code --dir <project-folder>
```

This creates the files below. If you already have one of them, add these entries to it by hand instead.

`.mcp.json`

```json
{
  "mcpServers": {
    "mindplace_local": {
      "type": "http",
      "url": "http://127.0.0.1:43731/mcp",
      "headers": {
        "Authorization": "Bearer ${MIND_PLACE_MCP_TOKEN}"
      }
    }
  }
}
```

`.claude/settings.local.json`

```json
{
  "permissions": {
    "allow": [
      "mcp__mindplace_local__memory_search",
      "mcp__mindplace_local__memory_fetch",
      "mcp__mindplace_local__context_build"
    ]
  }
}
```

Start Claude Code in that folder. When it asks whether to use the project server `mindplace_local`, say yes. The three tools then run without further prompts; any other tool still asks.

```powershell
claude
```

## Antigravity

Antigravity cannot read the key from a setting, so it talks to Mind Place through a small helper that reads the key from this window only. Copy `scripts/mcp-stdio-bridge.mjs` from the same Mind Place version into `%LOCALAPPDATA%\MindPlace\bin\` and check that its SHA-256 matches that version. It needs Node.js 20 or newer.

Write the two files into your project folder (existing files are never overwritten):

```powershell
node scripts/mcp-local-read-setup.mjs write antigravity --dir <project-folder>
```

This creates the files below (your own user name instead of `<you>`).

`.agents/mcp_config.json`

```json
{
  "mcpServers": {
    "mindplace_local": {
      "command": "node",
      "args": [
        "C:\\Users\\<you>\\AppData\\Local\\MindPlace\\bin\\mcp-stdio-bridge.mjs",
        "--url",
        "http://127.0.0.1:43731/mcp",
        "--token-env",
        "MIND_PLACE_MCP_TOKEN"
      ]
    }
  }
}
```

`.agents/mind-place-read.settings.json`

```json
{
  "permissions": {
    "allow": [
      "mcp(mindplace_local/memory_search)",
      "mcp(mindplace_local/memory_fetch)",
      "mcp(mindplace_local/context_build)"
    ]
  }
}
```

Start Antigravity in that folder with the read-only settings for this session:

```powershell
agy --settings .agents/mind-place-read.settings.json
```

## Never do this

- Never put the key in a file, a link, a command line or a screenshot.
- Never allow a whole server or a wildcard (`mcp__mindplace_local`, `mcp__*`, `mcp(*)`).
- Never start the tool with an option that approves everything (`--dangerously-skip-permissions`, bypass or auto-approve modes).
- Never mark Antigravity tools as `eager`; the larger read tools then stop working.

## Check that it works

Ask the tool: "Use only the mindplace_local tools. Search Mind Place for a word from a chat you allowed." It should find that chat, and nothing from chats you did not allow.

## Turn it off

In **Connections**, press **Revoke access** for that app. It stops working right away. Locking Mind Place also stops all access until you unlock and share again.
