# MP-8C · Memory/entity investigation lenses

Cloud-only implementation, issue #83, base 591a4ff19748917f190e51b72fbab6e282e82079. Adds Projects/People/Topics name-based investigation in the owner-unlocked Memories workspace. Uses only list_memory_inspection and get_memory_inspection, global visible claims, explicit search and claim-select, immutable provenance timeline and existing registered relations; search and detail generation fences prevent cross-view/lock leaks. This is NOT a canonical entity registry, cross-provider project identity, or graph-authority write surface. It cannot expose private/scoped/forgotten claims or access raw source text via source_ref. Native authoritative entity APIs are not available, so full entity registry/navigation remains for MP-8F/8L follow-on. Packaged Windows acceptance NOT_RUN.
